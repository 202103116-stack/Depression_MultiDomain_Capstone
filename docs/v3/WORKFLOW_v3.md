# WORKFLOW v3 — 건강 생활요인은 경제적 불리함을 상쇄하는가

> 부제: 2025 지역사회건강조사로 본 생활요인 축적과 우울 증상 격차의 역전점, 그리고 운동 요인의 추가 효과
> v2(다차원 요인 분석)는 태그 `v2-multidomain-final`로 동결했다(`docs/v2/WORKFLOW_v2.md`). v3는 브랜치 `v3-econ-reversal`의 `src/v3/`, `docs/v3/`, `outputs/v3/`, `report_v3/`에서 진행한다.
> 판단 근거는 `docs/decision_log.md` D-33~. 이 문서의 수치는 `outputs/v3/reports/*.csv`에서 옮겼고, 보고서는 `report_v3/report_data.json`에서 자동으로 가져온다.

## 서론 — 왜 이 주제인가
- v2에서 경제 영역과 건강 생활요인이 모두 우울 증상과 독립적으로 관련되었다. 여기서 질문이 나왔다. 경제적으로 불리한 사람이 생활요인을 많이 지키면, 생활요인이 적은 유리 집단보다 우울 증상이 적어지는 지점(**역전점**)이 있는가?
- 이론 틀: 자원 대체 vs 자원 증폭(Ross & Mirowsky, 2006), 근본 원인 이론(Link & Phelan, 1995). 선행 결합 연구로 Zhang et al.(2021, BMJ, 사망·심혈관질환)이 있다.
- 수업(스포츠융합산업프로젝트실습)과 연결하기 위해 뒷부분에 운동 요인 분석(S1 누적 효과, S2 종류 비교)을 넣었다.
- 가설: H1 격차, H2 기울기, H3 자원 대체(가법), H4 역전, RQ5 격차 분해, RQ6 운동 누적(S1), RQ7 운동 종류(S2).

## 6. 스포츠·운동 요인 — 완료 (`src/v3/exercise_v3.py`)
- **S1 운동 요인 누적 효과**: 운동 외 6개 단계를 표준화했다.
  - 소득 하위 20%: 운동 0개 6.4% → 1개 4.4% → 2개 4.1% → 3개 4.1%
  - 소득 상위 20%: 3.7% → 2.7% → 2.4% → 2.6%
  - 0→3개 변화: 하위 −2.3 [−3.5, −1.1], 상위 −1.0 [−1.9, −0.2], 차이 −1.3 [−2.7, +0.2]
  - 0→1개 단계의 차이: −1.0 [−1.8, −0.2]로 유의
  - 수급(−1.8 [−3.2, −0.3])·식품(−3.2 [−5.0, −1.4])은 불리 집단의 추가 감소가 유의하게 컸다.
  - 감소는 대부분 "0→1개"에서 나타났다. 신체활동 용량-반응이 낮은 구간에서 가장 가파르다는 결과(Pearce et al., 2022)와 일치한다.
- **S2 운동 종류**(세 운동 상호 조정, 소득)
  - 걷기: 하위 −1.8 [−2.2, −1.4], 상위 −0.5 → 차이 −1.3 [−2.0, −0.7], p < .001
  - 유산소: 하위 −0.7, 상위 −0.2 → 차이 n.s.
  - 근력운동: 하위 −0.7, 상위 −0.7 → 차이 0
  - 해석
    - 걷기는 비용·시설 없이 접근 가능해 불리 집단에서 의미가 크다.
    - 근력운동은 소득과 무관하게 관련되지만 실천율 격차가 크므로 접근성 지원이 필요하다.
    - 유산소는 업무 중 활동이 섞였을 가능성이 있다(신체활동 역설, Holtermann et al., 2018).
- 확장 개수(운동 외 6개 + 운동 3개 = 0~9개) 곡선: 하위 20%가 7개 이상에서 상위 20%와 거의 만난다(사용자가 처음 구상한 시각화).
