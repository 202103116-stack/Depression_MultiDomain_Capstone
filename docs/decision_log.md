## 분석·모델링

### D-14. 가중치 사용 범위 (2026-10-12)
- **결정**: EDA의 모집단 수준 비율(구성비, 양성률)은 `wt_p` 가중 비율. 표본 수는 비가중 N. ML 학습·평가에는 가중치를 넣지 않는다. 설계 기반 신뢰구간(층·집락 반영)은 아직 산출하지 않음 — 추후 조정 회귀 단계에서 별도 처리.
- **근거**: ML 목적은 개체 수준 분류이며 서베이 가중 추정은 별도 목적(SETUP_PROMPT 1장, docx 6장).

### D-15. 분할: 가구 단위 80/20 + 학습셋 내 가구 단위 층화 5-fold (2026-10-12)
- **결정**: 분석표본 231,271명을 `GroupShuffleSplit(test_size=0.2, random_state=42)`로 가구 단위 분할 → train 184,744명(109,349가구) / test 46,527명(27,338가구). CV는 `StratifiedGroupKFold(5, shuffle, seed 42)`.
- **근거**: 같은 가구원이 양쪽에 섞이면 성능 과대평가. 분할 결과는 `analysis_table.csv`의 `split` 열로 고정해 모든 모형이 같은 시험셋을 사용. 시험 양성률 3.90% vs 학습 3.73%(그룹 분할에 따른 자연 변동).

### D-16. 모형 설정: 사전 고정 하이퍼파라미터, 클래스 가중 없음 (2026-10-12)
- **결정**:
  - 결측 대치·원-핫 인코딩·표준화는 Pipeline 안에서 학습 데이터에만 적합. 수치형은 중앙값 대치 + 결측지시자.
  - 로지스틱: L2(C=1), 나이는 3차 스플라인(5 knots) — docx의 "나이의 유연한 항".
  - CatBoost(600회, depth 6, lr 0.05, 범주형 네이티브), RandomForest(300그루, min_samples_leaf 50), LightGBM(500회, lr 0.03, num_leaves 31, min_child_samples 100), MLP(64-32, early stopping), Dummy(사전확률).
  - 하이퍼파라미터 탐색 없음. 클래스 불균형 재가중 없음.
- **근거**: 이번 단계의 질문은 "정보 블록이 성능을 높이는가(H3)"이므로 알고리즘별 설정을 블록 간에 고정해 비교를 공정하게 한다. 재가중은 AP 순위에는 거의 영향이 없고 확률 보정을 깨뜨림. 튜닝은 향후 학습셋 CV 안에서만 수행(시험셋 잠금 유지).

### D-18. 평가 지표와 블록 간 비교 방법 (2026-10-12)
- **결정**: 주 지표 AP(PR-AUC). 보조로 ROC-AUC, Brier, 예측위험 상위 5%·10%의 정밀도/재현율, 보정곡선(10분위). M1~M3의 M0 대비 ΔAP·ΔAUC는 시험셋에서 **가구 단위 부트스트랩 1,000회** 95% CI로 제시.
- **근거**: 양성률 3.76% → 정확도는 무의미(all-zero 정확도 ≈ 96%). 같은 시험셋에서 대응 비교이므로 가구 단위 재표집으로 군집 상관 반영.

### D-19. 민감도 분석에서 M0 중복 학습 제거 (2026-10-12)
- **결정**: 친척·이웃 연락 민감도 분석은 M2·M3만 다시 학습하고, M0(연락 변수 없음)는 주 분석의 M0 예측을 공통 기준으로 재사용한다.
- **근거**: M0의 입력은 연락 변수와 무관해 결과가 동일하다. 실행 도중 발견해 고쳤고, 조합별 캐시(`data/processed/model_runs/`) 덕분에 완료된 19개 조합은 다시 학습하지 않고 이어서 실행했다. 결과에는 영향 없음.

### D-20. 인접 블록 간 비교를 별도로 보고 (2026-10-12)

### D-23. H2는 승법·가법 척도를 모두 보고하고, 결론은 절대 차이에 한정 (2026-10-12)
