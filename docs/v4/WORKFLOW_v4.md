## B. 생각1 — 스포츠 특이 시너지와 권고 조합 — 예정 (`src/v4/combo_v4.py`)
- **요인**
  - 스포츠 S = {걷기 실천, 중강도 이상 유산소, 근력 주 2일+, 신체활동 권고}
  - 일반 생활요인 L = {담배 미사용, 고위험음주 아님, 아침식사 주 5회+, 사회적 연결, 저녁 후 칫솔질}
  - 탐색용 생활요인: 수면 7~9시간, 이웃 신뢰, 동네 안전
- **쌍 단위 계산**: 쌍마다 조사설계 로지스틱(조정변수: 인구·경제·신체건강)으로 4칸 조정 유병률을 구한다.
  - 결합 감소 = 둘 다 − 둘 다 아님
  - 시너지 = 가법 상호작용(차이의 차이, RERI)
  - 승법 상호작용 p
- **① 생활요인 관점**
  - X ∈ L마다 대비를 계산한다: 대비 = 시너지(S, X) − X와 L의 다른 요인 쌍들의 평균 시너지
  - 대비가 음수이고 유의하면 X를 **스포츠 특이 짝**으로 본다.
  - 결합 감소로도 같은 대비를 낸다. CI는 조사설계 부트스트랩(PSU 재표집)으로 구한다.
- **② 스포츠 관점**: s ∈ S마다 결합 감소와 시너지가 큰 X의 순위를 낸다. 짝 간 동일성은 Wald 검정으로 본다.
- **③ 권고 조합**
  - 확인 세트에서 통과한 조합을 고르고, 충족률과 경제 집단별 감소 폭을 함께 적는다.
  - 예: "걷기 + 사회적 연결"
- **탐색 → 확인 절차**
  1. 탐색 세트(184,762명)에서 시도한다. 시도 범위는 운동 정의(일수, 시간, 권고), 생활요인 기준선, 층(성별, 연령대, 경제 집단), 결과(`y5`, `y_mood`)다.
  2. 시도는 모두 `outputs/v4/reports/c1_specs.csv`에 기록한다.
  3. 후보를 고른다. 규칙: 탐색 세트에서 대비 < 0이고 p < .05이며, 두 결과에서 방향이 같을 것.
  4. 확인 세트(46,528명)에서 후보만 검정한다(Holm 보정).
  5. 확인 세트의 `y_mood`·`y10`으로 방향을 재현한다.
- **판정 표기**
  - 확인 통과: "권고 조합"
  - 탐색에서만 유의: "탐색적 후보"
  - 차이 없음: "운동은 어떤 생활요인과도 효과가 더해지는 기본 축"
- **재사용 코드**
  - `src/v2/survey_regression_v2.py`: `recode`, `SPEC`, `design`, 조합 분석(5-2절)
  - `src/survey_regression.py`: `SurveyLogit`
  - `src/v3/exercise_v3.py`: 운동 요인 정의
  - `src/v3/common_v3.py`
- **선행연구(서지 확인 예정)**
  - Zhao et al.(2023): 건강 생활요인 결합과 우울
  - Schuch et al.(2018), Pearce et al.(2022): 신체활동과 우울
  - VanderWeele & Knol(2014): 가법 상호작용
  - 걷기·사회적 운동 관련 연구는 실행 단계에서 탐색한다.

## C. 생각2 — 다른 이진 결과로 모델링 — 예정 (`src/v4/train_cross_v4.py`)
- **모델**: CatBoost, 주 분석 53개 변수, v2 가구 단위 분할 승계(`src/v2/train_v2.py`의 분할·학습 함수 재사용)
  - 모델 A는 `y5`, 모델 B는 `y_mood`로 학습한다.
- **교차 예측**: 2 × 2 표(학습 결과 × 평가 결과)로 정리한다.
  - 지표: AP(무작위 기준 = 유병률), ROC-AUC, 보정 기울기
  - SHAP 상위 10개가 얼마나 겹치는지도 본다.
- **불균형 처리 비교**(D-42)
  - 비교할 방법: 보정 없음 / `auto_class_weights="Balanced"` / SMOTE-NC. 학습 폴드 안에서만 적용한다.
  - 판정 기준: AP, Brier, 보정 기울기
  - 기본 모델은 "보정 없음 + 임계값 운영점"이다(van den Goorbergh et al., 2022, *JAMIA*, 서지 확인 예정).
- **재사용**: `src/v2/performance_v2.py`(성능 CI, 보정, 운영점)

## D. 생각3 — 스포츠 조합 가중 모델 — 예정 (`src/v4/train_weighted_v4.py`)
- **조합 선택**: 탐색 세트에서 B의 결합 감소 상위 2개 스포츠 × 짝 조합을 고른다. 시험셋은 보지 않는다.
- **비교할 모델 세 개**(같은 분할, 5-fold 가구 그룹 CV + 시험셋)
  1. 기본 모델
  2. 조합 지시변수 추가
  3. `feature_weights`로 스포츠·짝 변수 가중. 가중값 후보는 CV로 고른다.
- **판정**
  - 시험 ΔAP와 짝지은 부트스트랩 95% CI
  - 보정
  - SHAP 상호작용값(스포츠 × 짝)
- 향상이 없으면 "트리 모델은 조합을 이미 학습한다"로 보고한다. 이 경우에도 스포츠 변수의 기여는 제시한다.

- **연결**
  - B에서 권고 조합이 나오면, 그 조합의 충족 여부 × 경제 집단의 3원 가법 대비를 본다. 질문은 "불리 집단에서 조합의 감소 폭이 더 큰가"다.
  - 권고 조합이 없으면 S1·S2 갱신만 한다.
