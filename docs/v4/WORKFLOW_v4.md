## B. 생각1 — 스포츠 특이 시너지와 권고 조합 — 완료 (2026-11-12, `src/v4/combo_v4.py`, `combo_patterns_v4.py`)
- **요인**
  - 스포츠 S = {걷기 실천, 중강도 이상 유산소, 근력 주 2일+, 신체활동 권고}
  - 일반 생활요인 L = {담배 미사용, 고위험음주 아님, 아침식사 주 5회+, 사회적 연결, 저녁 후 칫솔질}
  - 탐색용 생활요인: 수면 7~9시간, 이웃 신뢰, 동네 안전
- **쌍 단위 계산**: 쌍마다 조사설계 로지스틱(조정변수: 인구·경제·신체건강)으로 4칸 조정 유병률을 구한다.
  - 결합 감소 = 둘 다 − 둘 다 아님
  - 시너지 = 가법 상호작용(차이의 차이, RERI)
  - 승법 상호작용 p
- **① 생활요인 관점**
  - X ∈ L마다 대비를 계산한다: 대비 = 시너지(S, X) − X와 L의 다른 요인 쌍들의 평균 시너지
  - 대비가 음수이고 유의하면 X를 **스포츠 특이 짝**으로 본다.
  - 결합 감소로도 같은 대비를 낸다. CI는 조사설계 부트스트랩(PSU 재표집)으로 구한다.
- **② 스포츠 관점**: s ∈ S마다 결합 감소와 시너지가 큰 X의 순위를 낸다. 짝 간 동일성은 Wald 검정으로 본다.
- **③ 권고 조합**
  - 확인 세트에서 통과한 조합을 고르고, 충족률과 경제 집단별 감소 폭을 함께 적는다.
  - 예: "걷기 + 사회적 연결"
- **탐색 → 확인 절차**
  1. 탐색 세트(184,762명)에서 시도한다. 시도 범위는 운동 정의(일수, 시간, 권고), 생활요인 기준선, 층(성별, 연령대, 경제 집단), 결과(`y5`, `y_mood`)다.
  2. 시도는 모두 `outputs/v4/reports/c1_specs.csv`에 기록한다.
  3. 후보를 고른다. 규칙: 탐색 세트에서 대비 < 0이고 p < .05이며, 두 결과에서 방향이 같을 것.
  4. 확인 세트(46,528명)에서 후보만 검정한다(Holm 보정).
  5. 확인 세트의 `y_mood`·`y10`으로 방향을 재현한다.
- **판정 표기**
  - 확인 통과: "권고 조합"
  - 탐색에서만 유의: "탐색적 후보"
  - 차이 없음: "운동은 어떤 생활요인과도 효과가 더해지는 기본 축"
- **재사용 코드**
  - `src/v2/survey_regression_v2.py`: `recode`, `SPEC`, `design`, 조합 분석(5-2절)
  - `src/survey_regression.py`: `SurveyLogit`
  - `src/v3/exercise_v3.py`: 운동 요인 정의
  - `src/v3/common_v3.py`
- **결과**
  - **탐색**: 모형 1,458개, 대비 2,016개(결과 2 × 층 9 × 운동 7 × 생활요인 8 × 지표 2)를 모두 `c1_specs.csv`에 기록했다.
    - y5 대비 1,008개 중 82개가 후보 규칙을 통과했다.
    - p 순서 상위 5개는 모두 "걷기(또는 유산소) + 아침식사·담배 미사용"의 시너지 대비였다.
  - **확인(질문 ①)**: 후보 5개 모두 확인 세트에서 유의하지 않았다.
    - 가장 강한 후보는 전체 층의 걷기 + 아침식사 시너지 대비: −2.0%p [−4.3, +0.3], Holm p = .45.
    - PHQ-9 ≥ 10에서는 유의했고(−1.4 [−2.5, −0.2]), y_mood에서는 유의하지 않았다.
    - 따라서 **"스포츠와 짝지을 때만 특히 커지는 생활요인"은 확인되지 않았다(탐색적 후보로만 보고).**
  - **스포츠 관점(질문 ②, 확인 세트 y5)**: 운동마다 짝을 이룬 생활요인 사이에 결합 감소가 달랐다(동일성 p < .001).
    - 걷기의 짝: 칫솔질 −8.1 [−11.0, −5.1], 사회적 연결 −8.0 [−9.8, −6.2], 담배 미사용 −8.0 [−9.8, −6.1], 아침식사 −5.4, 음주 −3.8
    - 상위 세 짝은 서로 비슷하다. 시너지는 모두 0 근처로, 효과가 독립적으로 더해진다.
    - 걷기 + 사회적 연결은 y_mood(−3.0 [−4.2, −1.8])와 y10(−3.2 [−4.1, −2.2])에서도 재현되었다.
  - **패턴 확인(탐색에서 발견 → 확인 세트에서 1회 검정, `c1_patterns.csv`)**
    - P1 "운동은 다른 생활요인과 겹치지 않는다": 지지되지 않았다(모든 p > .1).
    - P2 "운동 + 사회적 연결의 결합 감소가 소득 하위 20%에서 더 크다"
      - **걷기**: 하위 −12.2%p, 상위 −3.9%p, 차이 −8.3 [−13.5, −3.1], Holm p = .007. y10에서 재현(차이 −4.0, p = .002), y_mood는 같은 방향이지만 유의하지 않음(−2.6, p = .15).
      - 유산소·근력·권고 충족도 같은 방향이지만 Holm 보정 후 유의하지 않았다(p = .18).
  - **권고 조합(질문 ③)**: **걷기 + 사회적 연결**
    - 확인 세트의 함께 충족률은 43.0%다.
    - 둘 다 충족한 사람의 y5 조정 유병률은 14.4%, 둘 다 아닌 사람은 22.4%다.
    - 소득 하위 20%에서는 결합 감소가 12.2%p로, 경제적 역전점 분석(단계 E)으로 이어진다.
    - 보조 권고: 담배 미사용·구강 관리와 걷기의 조합도 비슷한 크기다.
  - **해석 주의**: 횡단면 자료다. 소득 하위 집단은 기저 유병률이 높아서, 가법 척도의 감소 폭이 커지는 부분이 있다(v3의 가법 상호작용과 같은 틀).
- **선행연구(서지 확인 예정)**
  - Zhao et al.(2023): 건강 생활요인 결합과 우울
  - Schuch et al.(2018), Pearce et al.(2022): 신체활동과 우울
  - VanderWeele & Knol(2014): 가법 상호작용
  - 걷기·사회적 운동 관련 연구는 실행 단계에서 탐색한다.

## C. 생각2 — 다른 이진 결과로 모델링 — 완료 (2026-11-12, `src/v4/train_cross_v4.py`)
- **모델**: CatBoost, 주 분석 53개 변수, v2 가구 단위 분할 승계(`src/v2/train_v2.py`의 분할·학습 함수 재사용)
  - 모델 A는 `y5`, 모델 B는 `y_mood`로 학습한다.
- **교차 예측**: 2 × 2 표(학습 결과 × 평가 결과)로 정리한다.
  - 지표: AP(무작위 기준 = 유병률), ROC-AUC, 보정 기울기
  - SHAP 상위 10개가 얼마나 겹치는지도 본다.
- **불균형 처리 비교**(D-42)
  - 비교할 방법: 보정 없음 / `auto_class_weights="Balanced"` / SMOTE-NC. 학습 폴드 안에서만 적용한다.
  - 판정 기준: AP, Brier, 보정 기울기
  - 기본 모델은 "보정 없음 + 임계값 운영점"이다(van den Goorbergh et al., 2022, *JAMIA*, 서지 확인 예정).
- **재사용**: `src/v2/performance_v2.py`(성능 CI, 보정, 운영점)
- **결과**(시험셋 46,528명, 가구 부트스트랩 95% CI)

| 학습 \ 평가 | y5 (유병률 16.3%) | y_mood (6.3%) |
|---|---|---|
| y5 학습 | AP 0.450 [0.437, 0.462], AUC 0.771 | AP 0.200 [0.185, 0.215] (유병률의 3.2배), AUC 0.731 |
| y_mood 학습 | AP 0.417 [0.405, 0.429] (자기 모델의 93%) | AP 0.218 [0.203, 0.233], AUC 0.747 |

  - y5로 학습한 모델은 다른 문항인 우울감 경험을 자기 결과 모델 AP의 92% 수준으로 맞힌다. 반대 방향도 93%다.
  - 두 모델의 SHAP 상위 10개 중 7개가 같다: 식품안정성, 나이, 성별, 낙상, 저작불편, 종사상 지위, 친구 연락. 전체 순위 상관은 0.73이다.
  - → 모델은 PHQ라는 척도를 따라 하는 것이 아니라 **우울 위험 자체**를 학습했다. 이것이 생각2의 답이다.
  - 참고: y5의 AP는 0.450으로 y10(0.283)보다 높다. 양성 비율이 커서 생기는 차이이므로, 성능은 반드시 유병률 대비 배수와 함께 읽는다.
- **불균형 처리 비교**

| 결과 | 방법 | AP | ΔAP vs 보정 없음 | Brier | O:E | 보정 기울기 |
|---|---|---|---|---|---|---|
| y5 | 보정 없음 | 0.450 | — | 0.114 | 1.02 | 1.03 |
| y5 | 클래스 가중치 | 0.449 | −0.000 [−0.002, +0.001] | 0.188 | 0.39 | 1.03 |
| y5 | SMOTE-NC | 0.435 | −0.014 [−0.018, −0.010] | 0.116 | 0.92 | 1.01 |
| y_mood | 보정 없음 | 0.218 | — | 0.054 | 1.03 | 1.03 |
| y_mood | 클래스 가중치 | 0.212 | −0.006 [−0.010, −0.002] | 0.184 | 0.16 | 1.00 |
| y_mood | SMOTE-NC | 0.188 | −0.030 [−0.036, −0.023] | 0.056 | 0.78 | 0.91 |

  - 불균형 보정은 판별력(AP)을 높이지 못했다. 클래스 가중치는 예측 확률을 크게 부풀렸고(O:E 0.16~0.39), SMOTE-NC는 AP를 낮췄다.
  - 따라서 **보정 없음 + 임계값 운영점**을 유지한다. 이는 van den Goorbergh et al.(2022)의 보고와 일치한다.

## D. 생각3 — 스포츠 조합 가중 모델 — 완료 (2026-11-12, `src/v4/train_weighted_v4.py`)
- **조합 선택**: 탐색 세트에서 B의 결합 감소 상위 2개 스포츠 × 짝 조합을 고른다. 시험셋은 보지 않는다.
- **비교할 모델 세 개**(같은 분할, 5-fold 가구 그룹 CV + 시험셋)
  1. 기본 모델
  2. 조합 지시변수 추가
  3. `feature_weights`로 스포츠·짝 변수 가중. 가중값 후보는 CV로 고른다.
- **판정**
  - 시험 ΔAP와 짝지은 부트스트랩 95% CI
  - 보정
  - SHAP 상호작용값(스포츠 × 짝)
- 향상이 없으면 "트리 모델은 조합을 이미 학습한다"로 보고한다. 이 경우에도 스포츠 변수의 기여는 제시한다.
- **결과**(시험셋, y5)
  - 선택된 조합(탐색 세트 결합 감소 상위 2개): 신체활동 권고 + 저녁 칫솔질(−7.5%p), 근력운동 + 저녁 칫솔질(−7.3%p)
  - 가중값은 학습셋 3-fold CV AP로 정했다: 2배 0.4302 > 5배 0.4256 → 2배.

| 모델 | AP [95% CI] | ΔAP vs M1 |
|---|---|---|
| M0 기본 | 0.4495 [0.4368, 0.4620] | −0.0003 [−0.0015, +0.0010] |
| M1 + 구성 변수 | 0.4498 [0.4369, 0.4621] | — |
| M2 + 조합 지시변수 | 0.4487 | −0.0011 [−0.0024, +0.0000] |
| M3 + 특성 가중(2배) | 0.4488 | −0.0011 [−0.0026, +0.0002] |

  - 조합을 명시하거나 가중해도 예측 성능은 변하지 않았다. 트리 모델은 변수 간 조합을 이미 학습하므로, 조합 정보는 예측보다 실천 권고에서 의미가 있다.
  - **SHAP 상호작용**: 운동 관련 상위 쌍은 신체활동량 × 종사상 지위(전체 3위)다. 업무 중 활동이 섞이는 신체활동 역설(Holtermann et al., 2018)과 맞는다. 이어서 나이 × 걷기 일수(14위), 친구 연락 × 신체활동 권고(21위)가 나왔다. 운동 × 사회적 연결이 모델 안에서도 상호작용한다는 점은 B 단계 P2와 같은 방향이다.
