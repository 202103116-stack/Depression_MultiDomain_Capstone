## 2. 핵심 X — 신체활동 (지침서 32쪽 지표 정의, 81~84쪽 문항)

### 걷기 `phb_01z1`, `phb_02z1`, `phb_03z1`
- 문항 3: "최근 1주일 동안 한 번에 적어도 10분 이상 걸었던 날은 며칠입니까?" (출퇴근·등하교·이동·운동 목적 걷기 모두 포함) → `phb_01z1` 0~7일, 77=거부, 99=모름.
- 문항 3-1: "이러한 날 중 하루 동안 걷는 시간은 보통 얼마나 됩니까?" → `phb_02z1`(시간), `phb_03z1`(분), 77/88(비해당)/99.
- **[확인]** 원시자료: `phb_01z1` = {0: 35,095, 1: 8,125, 2: 16,603, 3: 25,995, 4: 14,204, 5: 36,077, 6: 11,432, 7: 84,074, 77: 5, 99: 5}.
- **[검증]** `phb_02z1 == 88`(비해당) 35,095명 = `phb_01z1 == 0` 35,095명, 개인 단위로 완전 일치 → 비해당은 "걷기 0일이라 질문 생략"이며 걷기 미실천으로 분류해야 함(결측 아님).
- **[확인]** 지침서 걷기 실천율(`ph_b0200`) SAS 코드: 시간 0~24·분 0~59일 때만 분 환산, **`phb_01z1` 0~4일이면 시간과 무관하게 0**, 5~7일이면 30분 이상 1 / 미만 0. 판정 불가 = 일수 77/99(10명) + 5일 이상인데 시간 77/99(9명) = 19명.

### 근력운동 `pha_19z1`
- 문항 4: "최근 1주일 동안 팔굽혀펴기, 윗몸 일으키기, 아령, 역기, 철봉 등의 근력 운동을 한 날은 며칠입니까?"
- 코드: 1=전혀 하지 않음, 2=1일, 3=2일, 4=3일, 5=4일, **6=5일 이상**, 7=거부, 9=모름.

- **[확인]** 따라서 코드 3~6 = "주 2일 이상" → 연구설계 docx의 근력운동 실천 정의(3~6)가 코드 의미와 일치. 운동 강도·근육군·시간 정보는 없음.

- **[확인]** 문항 1-1 `oba_02z1` = **키(cm)**, 문항 1-2 `oba_03z1` = **몸무게(kg)**, 소수점 1자리, 77777=거부, 99999=모름. 순서·단위 확인함.
