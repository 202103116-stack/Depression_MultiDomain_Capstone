# 데이터 사전 v2 — 우울 증상의 다차원 요인 (확인된 사실)

> 1차 사전(`docs/data_dictionary.md`)의 변수(Y, 걷기·근력, 연락 빈도, 교육·혼인·세대유형, 소득 2단계, BMI, 만성질환 3종)는 그대로 승계한다. 이 문서는 **v2에서 새로 추가한 변수**만 다룬다.
> 표기: **[확인]** 지침서 문항·코드표와 원시자료 `value_counts()` 일치. **[검증]** 분기(비해당) 구조를 개인 단위로 대조해 `preprocess_v2.validate_branches()`에 assert로 고정. **[공식]** 지침서 지표 SAS 코드를 그대로 이식.
> 확인일: 2026-10-15. 수치는 원시자료 231,615명 기준(비가중). 지침서 쪽수는 인쇄 쪽 기준.

## 0. 변수 선정 원칙
- 원시자료 201열 전체를 지침서 변수설계표와 대조해 라벨을 확인한 뒤, 우울 증상의 원인 또는 동반 요인이 될 수 있는 문항을 8개 영역으로 분류했다.
- 영역 분류는 생물심리사회 모형과 사회생태 모형을 따랐다: 인구 / 경제 / 신체건강 / 건강행태 / 사회관계 / 생활환경 / 의료접근·건강정보 / 심리·증상근접.
- **심리·증상근접** 영역(스트레스, 수면, 주관적 건강, EQ-5D 4개 차원, 행복감, 침상와병, 인터넷·도박 지장, 인지장애)은 PHQ-9 문항과 개념이 겹치거나(수면, 피로, 집중, 흥미) 우울의 결과일 가능성이 커서 주 분석에서 제외하고 별도 비교에만 쓴다(decision_log D-25).
- 각 변수에 **수정 유형**을 붙여 제언의 근거로 쓴다(decision_log D-37). 기준은 제6차 국민건강증진종합계획(HP2030)의 분야 대응이다.
  - **A 개인 행동**: 본인이 고르는 행동(신체활동, 흡연, 음주, 식생활, 칫솔질, 연락·사회활동, 검진·접종, 수면 등)
  - **B 서비스·정책·환경**: 개인 노력만으로는 어렵지만 제도로 바뀌는 현재 상태(소득·식품안정성·직업, 체중·구강·낙상, 미충족 의료, 건강정보 이해능력, 동네 환경·이웃 신뢰 등)
  - **C 바꿀 수 없음**: 고정 속성·과거 진단·거주 구조(나이, 성별, 교육, 혼인, 세대유형, 만성질환 진단, 치매환자 가족, 지역, 주택유형 등)
  - 예전 "수정가능 예/아니오"는 A·B = 예, C = 아니오와 같다.
- 신체활동과 함께 볼 생활요인은 Zhao et al.(2023)의 우울 관련 건강 생활 영역에 영역당 1개 문항을 대응시켜 고른다(D-38, 아래 9절).
