# 중간 프로포절 발표 구성 — 우울 증상의 다차원 요인 분석 (v2.1)

> 대상: 스포츠융합산업프로젝트실습 지도교수진. 발표 10분 내외 + 질의응답.
> 원칙: 장마다 주장 한 문장(제목) → 근거 한 가지(그림·수치) → 말할 내용. 수치는 `paper/paper_data.json`에서 읽는다(손으로 옮기지 않음).
> 산출: `presentation/proposal_v2.pptx` (생성 스크립트 `presentation/build_proposal.js`)

## 디자인 원칙
- 제목은 결론 문장, 마침표 없음. 본문은 왼쪽 정렬.
- 색: 짙은 청록(주색) + 산호색(강조 한 가지) + 흰 바탕. 장식 띠·밑줄·아이콘 장식 없음.
- 차트는 PowerPoint 기본 차트로 그려 같은 글꼴·색 규칙을 따른다. 그림 파일은 부록에만 쓴다.
- 글꼴: 맑은 고딕 한 계열. 발표자 노트에 말할 내용을 넣는다.
