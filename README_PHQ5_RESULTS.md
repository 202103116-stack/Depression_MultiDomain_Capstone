# PHQ-9≥5 주 분석: 실제 재분석 결과

2025 지역사회건강조사, 원본 v2-multidomain 커밋26b6a206에서 분기한 새 실행이다. 코드·집계표·그림을 공개 포크의 codex/phq5-primary 브랜치에 공유한다. 원자료·개인행·개인 예측값은 포함하지 않는다.

## 기준과 분석범위

주≥5는 경도 이상 증상, 민감도≥10은 중등도 이상 증상이다. 동일한 원자료에서 Y만 바꾸고 바깥 가구 학습·시험 분할과 설명변수를 유지했다. ML은 LightGBM의 영역 추가·제거·TreeSHAP과 로지스틱 비교를 양 기준에서 수행했다. ≥5 CatBoost 전체53변수·가구5fold 검증도 완료했다. 원본의 여섯 알고리즘 전체 및 CatBoost 모든 영역 재현은 완료하지 않았다.

H1은 K0~2/3/4/5/6개와 연령·성별·교육·혼인상태·소득5분위, 신체건강의 추가 보정을 사용했다. 사회적 연결에 포함된1인가구를 다시 세대유형으로 보정하지 않았다. 원본 조정집합·0~1개 범주를 그대로 재현한 결과는 별도 `reg_v2_*`에 남겼다(≥5 OR0.779, ≥10 OR0.700).

AP는 양성률에 영향을 받는다. ≥5의 AP가≥10보다 높다고 더 좋은 분류문제를 해결했다고 결론내리지 않는다. ≥5 LightGBM AP95% CI는0.437–0.461, AUC95% CI는0.765–0.778이다. ≥5 완료 CatBoost 전체 모형은 AP0.450/AUC0.772로, 성능 우월성 검정을 한 것은 아니다.

## 경제적 수준과 역전 해석

소득5분위를 모두 적합하고1·5분위를 중심으로 공통 C분포에 표준화했다. 신체건강 추가보정에서 K×소득 공동검정은≥5 p=2.26×10⁻⁶, ≥10 p=0.0258이다. 같은 K에서 소득1분위와5분위의 증상 비율 차이는 남는다. ≥5에서0~2개12.4%p에서6개2.2%p로 작아지는 패턴이다. 이는 개인의 변화나 인과적 격차 해소가 아니다.

서로 다른 K의 비교에서는 소득1분위5·6개가 소득5분위0~2개보다 낮게 추정됐다. 그러나 소득5분위 평균을 기준으로 한6개 범주의 역전은≥5에서 원p0.0313/10개 비교 Holm p0.0626, ≥10에서는p0.479로 견고하지 않다. ‘경제적 불리함을 상쇄했다’는 결론은 지지하지 않는다.

## 해석의 한계와 다음 검토

횡단면·자기보고·잔여 교란·대리측정·동일가중 지수의 한계가 있다. 실제 운동 처방·우울증 진단·미래 발병 예측·프로그램 개입 효과를 검증하지 않았다. 신체건강을 추가 보정하면 매개/과잉조정 가능성이 있어 기본보정도 병행 보고했다.

사회적 연결은1인가구를 포함해 순수 개인행동이 아니다. 원본 사회지수는 이웃 경조사 문항의 모름9도 ‘참여 확인 안 됨’으로 분류한다. 원자료에서 해당9코드는4,861명이다. `h1_score6.py --social-unknown-missing`은 이를 결측으로 바꾼 H1 민감도이며 별도 CSV로 보존한다. 이 대안과1인가구 제외 대안은 지수의 측정 타당성을 판단할 때 함께 고려해야 한다.

모름9를 결측으로 처리한 ≥5 H1: n=223,643, OR0.772[0.759, 0.786].

모름9를 결측으로 처리한 ≥10 H1: n=223,643, OR0.691[0.670, 0.714].

## 파일 안내

- `src/analysis_config.py`: 주 분석5·민감도10 및 경로 격리
- `src/v2/run_lgbm_core.py`: ML 영역 정보·TreeSHAP·가구 부트스트랩
- `src/v2/h1_score6.py`: 정합성을 맞춘 H1 점수 분석
- `src/v2/economic_lifestyle.py`: 경제집단·상호작용·표준화 비율·Holm 보정
- `src/v2/audit_reanalysis.py`: 양 기준의 X/분할 일치·가구 누수·정의 검증
- `outputs/phq5/v2/`, `outputs/phq10/v2/`: 새 집계표·그림
- `reg_v2_*`: 원본의 조정 집합을 재현한 별도 참고 결과
- `data/`: 원자료·가공 개인행·개인 예측값, Git 및 검토 ZIP에서 제외
